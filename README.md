 # Meeting Transcriber                                                         
                                                                                
  Upload a meeting recording, get back a Word doc with a summary, key points,   
  action items, and sentiment analysis.                                         
                                                                                
  Uses OpenAI Whisper for transcription and GPT-4 for analysis.                 
                                                                                
  Built as an early experiment with AI APIs and Streamlit when I was learning   
  how to string together different AI services. It worked, but I'd do it         
  differently now.
